Trading tests

Static archive of how the published agent decides, then a paper decision you can run from the same edge rule. Nothing here reads a saved run folder, calls a model, or sends an order.

How a decision is made

News, or the scheduled check about 60 minutes before tip, starts the loop. The agent investigates, then forecasts: the Kalshi mid from about 24 hours before tip, plus the M4 news shift, clipped to [0.02, 0.98]. The edge after the fee 0.07·p·(1−p) on the contract price must be greater than 4¢. Checks run next, then an optional sceptic veto, then the risk caps. The result is a paper fill or a logged pass.

Paper decision by the trading agent

This uses the published edge rule, not a new live sceptic call. Paper only: no Kalshi order, no Polymarket order, and no LLM call.

The trading agent forecasts clip(Kalshi mid about 24 hours before tip + M4 news shift, 0.02, 0.98), then applies edge = p − ask − 0.07·ask·(1−ask). A paper fill requires that edge, in cents, to be strictly greater than 4¢. If the anchor, the M4 shift, or a live quote is missing, the result says so and uses these form inputs. It does not invent a price. The fee uses the executable ask. In the archive above, p in 0.07·p·(1−p) is that contract price.

Published caps: $20 stake, $50 per order, $100 per game, $300 per day. This page clamps the paper stake and names the cap that binds. Totals stay in this browser tab. Nothing is sent to Kalshi or Polymarket.
